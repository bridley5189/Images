## 🎯 Purpose

- **Asset Storage** - Centralized location for reusable image assets
- **Version Control** - Track changes to branding and design elements
- **Easy Access** - Quick reference links for use in other projects
- **Backup** - Cloud-based backup of important visual assets

## 🔗 Usage

Images can be referenced directly via GitHub raw URLs:

```markdown
![Logo](https://raw.githubusercontent.com/bridley5189/Images/main/RidleyLogo.jpeg)
```

Or in HTML:

```html
<img src="https://raw.githubusercontent.com/bridley5189/Images/main/RidleyLogo.jpeg" alt="Logo">
```
